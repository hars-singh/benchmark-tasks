# Rolling batch coding on a moving carton

Friction-driven code printers transfer a batch code as packaging travels past a rolling die. This bench task uses a handheld roller coder and a linear stage to test registration and steady contact while a carton moves. [Pannier inline code printers](https://www.pannier.com/industrial-printers/flexographic/code-printers/), [Röltgen roller stamp](https://www.roeltgen.de/en/product/roller-stamp/)

Build the aluminum stage, print wheel, cradle and coder from the supplied geometry. Use a blank kraft carton and a roller die with the seven-column B7 pattern, including its blank separator. Print or draw a 28 by 44 mm inspection box on the carton before mounting it at the documented offset. Secure the carton to the stage and reset the wheel to its index position. The working pass is the forward stroke of the stage.

Use overhead video to inspect the mark against a millimeter grid. Confirm the tool made one rolling pass, the B7 columns are registered, and the coder rests upright in the cradle with both hands clear. Simulation carries the carton on its native stage and evaluates native contact and rotation. It reveals individual columns on the carton when die angles pass through loaded, low-slip contact. The physical reference uses a real inked die on a fresh carton for every trial.
